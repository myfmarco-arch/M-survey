# Writing rules (minimal English)

This file is a product choice, not a framework requirement. It can be replaced by an overlay.

## Respondent-facing text

- Use short, plain sentences.
- One main concept per question.
- State the object, the time frame and the situation.
- Do not show internal metric names, hypotheses, analysis terms or programmer language.
- Delete pleasantries that carry no information.

## Delivery text

- For an audit, lead with the actionable problems and their severity.
- For method advice, state the assumption behind the recommendation and the limit of the conclusion.
- Keep reasoning out of the final questionnaire.
