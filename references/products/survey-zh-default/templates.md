# 问卷模板

根据任务删减不需要的部分。简单问卷不必补齐所有章节。

```markdown
# [问卷名称]

## 一、研究目标

- [目标一]
- [目标二]

## 二、样本框架（仅在项目需要且依据充分时使用）

| 分组 | 样本条件 | 有效样本数 | 配额说明 |
|---|---|---:|---|
| [组别] | [条件] | [按样本规划填写] | [说明依据和用途] |

需要用表格说明样本框架时，优先使用以下字段：

| 项目 | 内容 |
|---|---|
| 目标人群 | [纳入条件；需要重点分析的用户子群可写在这里] |
| 排除条件 | [内容] |
| 样本来源 | [名单随机抽样、App 内邀约、样本供应商等] |
| 有效样本数 | [计算所得或项目建议的数字，并注明是哪一种；依据见样本规划] |
| 配额或比较 | [仅在有明确结构或比较需求时填写] |

“样本来源”必须填写（`sampling.population-defined`）。“主要分析人群”和“外推限制”默认不单列；只有样本来源会改变结果解释时，才在正文外补充必要边界。完整的计算参数按 [样本规划](../../services/sample-planning.md) 的交付格式另行说明。

## 三、问卷框架

| 模块 | 研究内容 | 主要题型 | 预计时长 |
|---|---|---|---|
| 信息甄别 | [内容] | [题型] | [时长] |
| 主问卷 | [内容] | [题型] | [时长] |
| 背景信息 | [内容] | [题型] | [时长] |

## 四、问卷正文

### 卷首语

[说明主题和预计时长；触发个人信息或敏感信息风险时，按隐私与法律风险规则补充必要告知。]

## Part 1. 信息甄别

##### Q1.【题目标签】【ALL】[题干]【单选，必答】

| 编码 | 选项细节 | 程序标签 |
|---:|---|---|
| 1 | [选项] |  |
| 2 | [选项] |  |
| 98 | 其他，请注明____ | 置底；开放填空 |

## Part 2. 主问卷

##### Q2.【题目标签】【显示条件】[题干]【多选，选项随机，必答】

| 编码 | 选项细节 | 程序标签 |
|---:|---|---|
| 1 | [选项] |  |
| 2 | [选项] |  |
| 98 | 其他，请注明____ | 置底；开放填空 |
| 99 | 以上都没有 | 置底；排他 |

## Part 3. 背景信息

[只保留分析、配额或招募需要的变量。]
```

最终问卷默认不增加独立的“基础编码说明”章节。编码要求通过题目标题、选项编码、程序标签和变量名表达；用户明确要求基础编码、SPSS 配置或数据字典时，再另行交付。

## 简短研究简报

完整问卷前需要确认方案时，使用以下格式：

```markdown
## 研究简报

| 项目 | 内容 |
|---|---|
| 业务决策 | [内容] |
| 评价对象与阶段 | [内容] |
| 目标人群 | [内容] |
| 核心研究问题 | [内容] |
| 主要方法 | [内容] |
| 样本与比较 | [内容] |
| 待确认项 | [仅列会改变方案的事项] |
```

## 修改问卷

修改已有问卷时：

1. 保留原有题号、变量名和有效编码。
2. 只修改与研究目标有关的部分。
3. 新增题目使用不冲突的编号。
4. 变更历史口径时明确指出可比性影响。
5. 最终交付只保留修改后的终版，不混入讨论记录和删除内容。
6. 最终正文不保留“待定”“待确认”或未解释占位符。

## 审核问卷

审核结果按严重程度排列。中文标签与 [验证合同](../../contracts/validation-contract.md) 的级别一一对应：

| 级别 | 验证合同级别 | 含义 |
|---|---|---|
| 严重 | `error` | 会导致样本错误、方法无效、逻辑中断或数据不可用 |
| 重要 | `warning` | 会造成理解偏差、分析困难或明显作答负担 |
| 建议 | `info` | 不影响基本使用，但可提高一致性和效率 |

每项问题写明题号、问题、影响和建议。可以附上对应的 `rule_id`，便于团队追踪。没有问题时明确说明剩余风险和未验证内容。

审核表格格式：

```markdown
| 级别 | 题号 | 问题 | 影响 | 建议 |
|---|---|---|---|---|
| 严重 | Q5 | 未使用者也会看到满意度题 | 无经验者评价真实体验，数据不可解释 | 增加使用资格题，Q5 只向使用者显示 |
```

## 模板规则

| rule_id | 检查 | 默认严重程度 |
|---|---|---|
| `format.no-coding-section` | 最终问卷不单独附加“基础编码说明”；用户明确要求时才另行交付 Codebook 或 SPSS 配置 | `info` |
| `format.audit-table` | 审核结果使用“严重 / 重要 / 建议”标签和“级别、题号、问题、影响、建议”五列 | `info` |
