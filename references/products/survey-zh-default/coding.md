# 官方默认编码

本文件只定义 `survey-zh-default` 在项目没有现有编码、用户没有指定编码、平台也不自动管理编码时使用的默认值。

## 默认值

| 语义 | 默认编码 |
|---|---:|
| 普通选项 | 1、2、3…… |
| 其他 | 98 |
| 以上都没有 | 99 |

这些数字是官方产品默认值，不是问卷方法、SPSS 或框架合同的要求。

不知道、不记得、不适用和拒答没有官方默认编码。需要这些选项时，使用项目或用户约定的编码；没有约定时先确认，不自行占用有效选项编码。官方示例使用 `97 = 不记得 / 说不清`，那是示例项目的约定，不是默认值。

## 覆盖条件

以下任一条件成立时，不使用上述默认值：

- 问卷已经开始回收。
- 历史追踪问卷已定义题号、变量名或编码。
- 用户或组织明确提供了编码规范。
- 问卷平台管理底层编码。
- overlay 启用了其他编码配置。

## 语义要求

不论使用什么数字或字符串，都必须满足：

- 题目和选项标识唯一、稳定。
- “其他”与对应的开放文本字段关联。
- “以上都没有”与其他普通选项排他。
- 不知道、不适用、拒答和系统缺失的语义分开。
- 随机展示不改变编码。
