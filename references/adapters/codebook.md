# Codebook 适配器

仅在用户要求完整数据字典、SPSS 分析配置、跨波次管理或平台交付时读取本文件。

## 交付级别

| 级别 | 内容 |
|---|---|
| 基础编码 | 题号、变量名、选项值、特殊选项语义、多选拆分和矩阵子变量 |
| 完整 Codebook | 基础编码加变量属性、缺失规则、来源、显示条件和派生规则 |
| 分析配置 | 完整 Codebook 加多选题组、权重、随机组、展示顺序、波次映射和分析语法说明 |

问卷默认不单独交付编码说明。用户明确要求“基础编码”或“SPSS 编码”但未说明深度时，先确认需要基础编码还是完整 Codebook。

## 完整 Codebook 字段

| 字段 | 要求 |
|---|---|
| 变量名 | 唯一、稳定，符合项目命名约定 |
| 变量标签 | 使用简短完整的题意，不只写题号 |
| 来源题 | 题号及矩阵行、循环项或派生来源 |
| 类型 | 数值、字符串、日期或时间 |
| 宽度与小数位 | 按实际取值设置 |
| 值标签 | 覆盖所有封闭选项 |
| 用户缺失 | 不知道、不适用、不愿透露等明确回答 |
| 系统缺失 | 未展示、未作答或无记录；不要与用户缺失混用 |
| 测量水平 | 名义、顺序或尺度 |
| 显示条件 | 变量在哪些受访者和条件下产生 |
| 派生规则 | 总分、反向题、标准化、分组和计算公式 |
| 备注 | 版本、来源、量表许可或特殊分析要求 |

## 类型规则

- 日期使用统一格式，并保存原始值和必要的派生日期变量。
- 金额记录货币和单位；小数位与实际精度一致。
- 字符串设置合理最大长度，不截断开放回答。
- 反向题保留原始变量，另建派生变量或在语法中明确转换。
- 多题量表保留每道原始题，再生成总分或维度分。
- 随机组、刺激版本、展示顺序和循环位置使用独立隐藏变量。

## 缺失值

- “其他”和“以上都没有”通常是有效回答，不自动设为缺失。
- 它们的具体数字或字符串来自当前产品、overlay 或平台编码。Codebook 适配器不强制 `98/99`。
- 不知道、不记得、不适用和不愿透露使用项目约定的独立编码。
- 项目没有缺失值约定时，先确认，不自行占用有效选项编码。
- 因显示条件未进入题目时使用系统缺失或项目约定的结构性缺失，不编码成“否”。

## 多选题组

默认每个选项保存为独立 0/1 变量；产品或 overlay 可以替换存储方式（例如多响应变量），但必须保留每个选项可单独分析。Codebook 说明题组名称、成员变量、计数值和排他规则。表示“以上都没有”的变量为 1 时，其他普通选项必须为 0。

## 权重与跨波次

- 权重变量说明目标总体、加权维度、基准来源、截尾规则和适用分析。
- 跨波次保持变量名、值标签、量表方向、召回期和特殊选项一致。
- 发生变更时保留旧变量映射，并说明可比性影响。

## Codebook 表格

| 变量名 | 变量标签 | 来源题 | 类型 | 值/值标签 | 缺失规则 | 测量水平 | 显示条件 | 派生规则 | 备注 |
|---|---|---|---|---|---|---|---|---|---|
| [变量] | [标签] | [题号] | [类型] | [内容] | [内容] | [水平] | [条件] | [规则] | [备注] |

最终交付不保留未知编码或待确认占位符。无法确定时，在 Codebook 外列出阻断项。

## 验证

| rule_id | 检查 | 默认严重程度 |
|---|---|---|
| `adapter.codebook.complete` | 每个题目、矩阵行、多选选项、开放文本和隐藏变量都有对应变量 | `error` |
| `adapter.codebook.missing-distinct` | 用户缺失和系统缺失分开；未展示不编码为“否” | `error` |
| `adapter.codebook.multi-group` | 多选题组说明成员变量和排他规则 | `warning` |
| `adapter.codebook.derived-rules` | 反向题、总分和派生变量保留原始变量并写明公式 | `warning` |
| `adapter.codebook.no-placeholder` | 不保留未知编码或待确认占位符 | `error` |
