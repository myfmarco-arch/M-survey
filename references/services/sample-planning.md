# 样本规划

仅在任务要求样本量或配额建议时读取本文件。

## 输出边界

- 不用 `n=300`、`n=500` 等常见数字代替计算。
- 参数不足时，不自行推导精确总样本、每格样本或邀约量。若项目已经给出建议值，可以记录为项目建议的最低有效样本数，但不能把它写成基于允许误差或统计功效计算得出的样本量建议。
- 可以输出计算所需参数、计算关系和带明确假设的情景范围。
- 便利样本不能通过增加样本量或设置配额变成概率样本。

## 先确定分析目标

样本规划先确定以下内容：

1. 主要研究问题和主要结果指标。
2. 目标总体和样本来源。
3. 需要比较的最小分析单元。
4. 描述总体、比较差异、估计模型，还是执行特殊实验设计。
5. 允许误差、预期差异或模型复杂度。
6. 筛选、完访和重复测量流失。

主要目标不明确时，不给精确样本量。

## 常规描述性调查

估计比例时，至少需要：

- 置信水平；
- 允许误差；
- 预期比例；未知时可用最保守值并明确说明；
- 总体规模是否需要有限总体修正；
- 抽样设计和预期设计效应；
- 是否需要分别报告子群。

简单随机抽样下的初始样本关系：

```text
n0 = z² × p × (1-p) ÷ e²
```

`z` 为置信水平对应值，`p` 为预期比例，`e` 为允许误差。非概率样本不得用该公式包装成总体代表性保证。

估计均值时，还需要结果变量的标准差或可用的历史估计。没有标准差时，不输出精确样本量。

## 组间比较和实验

至少需要：

- 主要结果变量类型；
- 最小有意义差异或目标效应量；
- 显著性水平；
- 统计功效；
- 组数和分配比例；
- 单侧或双侧检验；
- 结果比例或标准差的先验估计；
- 重复测量时的相关性和流失率。

缺少关键参数时，列出缺口，不生成精确每组样本。正式功效分析应使用可复核的统计工具，并保留输入参数。

## 复杂方法

以下方法不能使用统一经验阈值：

| 方法 | 必须先确定的设计参数 |
|---|---|
| MaxDiff | 候选项数量、每任务展示数、任务数、设计版本、目标分析层级和分群需求 |
| 选择型联合分析 | 属性与水平、每任务方案数、任务数、设计效率、先验参数、分析模型和分群需求 |
| 驱动模型 | 结果变量、预测变量数量、预期效应、共线性、验证方式和缺失处理 |
| 分群 | 分群变量、预期类别、模型选择、稳定性验证、留出样本和最小可行动群体 |
| 重复测量 | 测量次数、组数、组内相关、主要对比和预期流失 |

设计参数不足时，只说明需要补充什么，不编造样本量。

## 从有效样本反推邀约量

```text
邀约量
= 目标有效样本
÷ 目标人群发生率
÷ 筛选通过率
÷ 完访率
```

每个比例必须来自历史数据、供应商数据、预测试或明确假设。缺少依据时给情景范围，不给单一精确值。

结构配额用于接近目标总体结构。分析配额用于保证关键比较单元。等额分析配额不能解释为自然总体结构；需要总体估计时说明加权方案和可能的设计效应。

## 交付格式

参数充分时：

| 项目 | 内容 |
|---|---|
| 主要分析 | [内容] |
| 最小分析单元 | [内容] |
| 输入参数 | [内容] |
| 计算方法或工具 | [公式或工具，以及计算过程] |
| 计算所得有效样本数 | [由上面的参数计算得到的数字] |
| 项目建议最低有效样本数 | [项目或用户给出的数字；没有时写“项目未另行给出”，不自行编造] |
| 损耗假设 | [每个比例及其来源：历史数据、供应商数据、预测试或明确假设] |
| 建议邀约量 | [单一值或情景范围；比例缺少依据时只给范围] |

“计算所得有效样本数”和“项目建议最低有效样本数”分开填写。两者不一致时，说明以哪个为准及原因。

参数不足时，只输出：

- 当前可以确定的样本结构；
- 缺失参数；
- 参数如何影响结果；
- 取得参数后采用的计算方法。
