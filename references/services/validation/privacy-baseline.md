# 隐私与法律风险

触发条件：涉及未成年人、个人信息、敏感信息、联系方式、数据关联、多市场、第三方处理或跨境时读取并执行本文件。未触发时不读取，也不在交付物中附加隐私说明。

本文件用于问卷设计阶段的风险初筛，不构成法律意见，也不能证明问卷符合任何法律。

## 规则

| rule_id | 检查 | 默认严重程度 |
|---|---|---|
| `privacy.minor` | 目标人群包含未成年人，但没有已批准的监护人同意与伦理方案 | `error` |
| `privacy.high-risk-data` | 收集身份证件、生物识别、精确位置、健康等高风险信息，但无法说明必要性和保护措施 | `error` |
| `privacy.data-linkage` | 问卷答案与实名账号、订单、CRM、设备标识或行为日志关联，但没有明确告知和授权安排 | `error` |
| `privacy.cross-border` | 涉及跨境传输或多市场统一存储，但没有明确数据流向和责任方 | `error` |
| `privacy.deceptive-purpose` | 要求隐瞒数据用途、绕过同意或规避参与者权利 | `error`，并拒绝该要求 |
| `privacy.minimization` | 个人信息题未说明用途，或可用区间、类别代替精确值却未代替 | `warning` |
| `privacy.contact-separation` | 联系方式未与分析数据分离，或未在同意后续联系后收集 | `warning` |
| `privacy.notice` | 卷首告知缺少触发条件要求的内容，或包含无法兑现的承诺 | `warning` |
| `privacy.no-compliance-claim` | 输出“已符合 GDPR”“已符合个人信息保护法”等合规结论 | `error` |

## 风险结果

| 结果 | 处理 |
|---|---|
| 无明显个人信息风险 | 正常继续，不附加法律说明 |
| 存在可控制风险 | 最小化收集，并补充必要告知、同意和保存说明 |
| 高风险或条件不明确 | 停止生成相关题目，列出需要隐私、法务或伦理负责人确认的事项 |

## 硬停止时的处理

上表中默认严重程度为 `error` 的规则是硬停止条件。触发时：

- 不生成可投放版本，也不生成触发风险的相关题目。
- 未成年人：默认只面向成年人。要求改为成年人，或提供已批准的监护人同意与伦理方案。
- 隐瞒用途、绕过同意或规避参与者权利：直接拒绝该部分要求，可以继续设计不涉及隐瞒的版本。
- 其他情形：列出需要隐私、法务或伦理负责人确认的事项，确认后再继续。

## 个人信息最小化

设计每个个人信息题前确认：

1. 该信息是否直接服务于筛选、配额、分析或后续联系。
2. 是否可以使用区间、类别或匿名标识代替精确值。
3. 是否可以设为选答，并提供“不愿透露”。
4. 是否需要与问卷答案分开保存。
5. 谁可以访问，保存多久，何时删除。

联系方式仅向同意后续联系的人收集。联系方式应进入独立表单或独立数据表，不在分析数据中保留直接标识符。

## 敏感信息

以下内容需要更高保护：

- 健康、残障、遗传和生物识别；
- 种族或民族、宗教、政治观点和工会身份；
- 性生活和性取向；
- 精确位置、身份证件和金融账户；
- 收入、财产和其他项目定义的敏感个人信息；
- 不满十四周岁未成年人的个人信息。

只有研究确有必要且已确定合法处理条件时才设计相关题目。优先使用区间，允许跳过或选择“不愿透露”，并避免把敏感答案直接暴露给不需要访问的人员。

## 卷首告知最低内容

按项目需要说明：

- 研究主题和参与内容；
- 预计时长；
- 自愿参与和可退出；
- 收集的数据类型和用途；
- 是否有后续联系、数据关联或第三方处理；
- 保存期限或确定期限的方法；
- 联系方式和权利请求渠道；
- 奖励条件；
- 适用时的跨境或多市场数据处理。

不要把无法兑现的承诺写入卷首语。数据匿名化后无法定位个人记录时，不承诺可以随时删除单份匿名回答。

## GDPR 风险初筛

涉及欧洲经济区或英国时，至少确认：

- 数据处理目的和合法依据；
- 透明告知；
- 目的限制和数据最小化；
- 准确性、保存期限和访问控制；
- 参与者权利的受理方式；
- 控制者、处理者和第三方平台关系；
- 敏感数据的额外条件；
- 跨境传输安排；
- IP、Cookie、设备信息等平台自动采集数据。

不要输出“已符合 GDPR”。输出“已完成问卷层面的风险初筛，最终合规性需要项目隐私或法务负责人确认”。

## 中国个人信息保护风险初筛

涉及中国大陆时，至少确认：

- 处理目的、方式和信息范围是否明确且必要；
- 是否涉及敏感个人信息和单独同意；
- 是否涉及不满十四周岁的未成年人和监护人同意；
- 是否委托问卷平台、样本供应商或其他第三方处理；
- 是否向境外提供个人信息；
- 保存期限、访问范围和删除安排；
- 联系方式与问卷答案是否分离。

不要输出“已符合个人信息保护法”。需要法律判断时，标记法务或隐私复核。

## 最小交付

只报告实际触发的风险：

```text
隐私与法律风险：高 / 中 / 低
触发条件：[内容]
问卷设计处理：[内容]
需外部确认：[仅列阻断项]
```

普通、匿名且不涉及敏感内容的问卷不附加本节。
