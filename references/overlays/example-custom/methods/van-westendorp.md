# Van Westendorp 价格敏感度测量

本文件是 overlay 新增方法模块的示例。方法依据见官方 [方法目录](../../../modules/methods/catalog.md) 中的 P01 条目和 E23。

## 解决的问题

探索目标用户认为某产品或服务在什么价格上“太便宜”“便宜”“贵”和“太贵”，得到陈述性的可接受价格区间，用于早期定价讨论。

## 适用条件

- 产品或服务的价值和价格单位可以清楚描述，例如“每月订阅费”。
- 受访者对该品类有足够经验或已看过完整概念说明。
- 业务需要的是价格区间的初步判断，而不是精确需求曲线。

## 不适用条件

- 需要估计明确价格点下的购买概率。此时优先考虑 Gabor-Granger。
- 价格需要与功能、品牌或服务水平一起权衡。此时优先考虑含价格属性的选择型联合分析。
- 受访者无法理解产品价值或价格单位。
- 需要预测真实销量或收入。

## 必需输入

- ResearchBrief 中的 `decision`、`object` 和 `target_population`。
- 价格单位、货币和计费周期。
- 产品概念说明或刺激材料。
- `experience_stage`：受访者是否了解该品类或已看过概念。

## 设计和样本要求

- 四道价格题使用同一货币、同一价格单位和同一计费周期。
- 题目顺序固定为：太便宜、便宜、贵、太贵；或在全项目内统一使用另一顺序。
- 数值题设置合理的上下限，并检查四个回答的逻辑顺序（太便宜 ≤ 便宜 ≤ 贵 ≤ 太贵）。逻辑不一致的回答在分析前定义处理规则。
- 样本量按需要比较的子群和区间估计精度规划，不套用统一阈值。

## 产生的输出

- MethodPlan：价格单位、刺激材料、逻辑检查和分析方法。
- QuestionnaireSpec：四道数值题，`construct: preference`，并附逻辑检查说明。
- 分析说明：四条累积曲线、交点和可接受价格区间。

## 允许的结论

- 在当前人群、概念说明和价格单位下，陈述的可接受价格区间。
- 不同子群陈述区间的差异，前提是子群样本足够。

## 不允许的结论

- 不将交点解释为“最优价格”或收入最大化价格。
- 不将可接受区间解释为真实支付意愿或需求曲线。
- 不将结果外推到未展示的产品版本、价格单位或竞争情境。

## 验证规则

| rule_id | 检查 | 默认严重程度 |
|---|---|---|
| `method.van-westendorp.same-unit` | 四道题使用同一货币、价格单位和计费周期 | `error` |
| `method.van-westendorp.order-check` | 定义四个回答的逻辑顺序检查和不一致回答处理 | `warning` |
| `method.van-westendorp.no-optimal-price` | 结论没有把交点称为最优价格或真实支付意愿 | `error` |
