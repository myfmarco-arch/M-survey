# 条件追问与执行约束

需求澄清的第二层问题。只在 [首轮核心问题](clarification-questions.md) 的答案触发条件主题、或需要执行约束参数时读取。

文件用途和问题 ID 的数据源见 [澄清问题集合](clarification-questions.md)。

## 1. 条件追问

只在核心回答触发对应目标时询问。每次追加 1–3 个问题。

| ID | 触发主题 | 建议追问 | 方法判断 |
|---|---|---|---|
| F01 | 功能优先级或需求排序 | 您要判断每项功能属于基本需求、期望需求还是魅力需求，还是只要得到多个需求的相对排序？ | 基本/期望/魅力考虑 N01 KANO；相对排序考虑 N02 MaxDiff。不要用 KANO 代替排序。 |
| F02 | 产品组合或属性权衡 | 用户是否需要在功能、价格、品牌或服务水平之间做真实取舍？候选属性和水平是否已经确定且可落地？ | 是则考虑 N03 选择型联合分析；不真实时先探索和预测试。 |
| F03 | 功能题设计 | 候选功能能否写成用户可理解的“有”和“没有”，或明确的属性水平？ | 影响 KANO 成对题、MaxDiff 候选项和联合分析属性设计。 |
| F04 | 满意度或服务体验 | 评价对象是刚完成的一次交易或服务，还是一段时间内的整体关系？最近一次体验发生在什么时候？ | 一次体验优先 X01 交易型 CSAT；长期关系考虑 X02。 |
| F05 | 努力、推荐或忠诚 | 您要测总体评价、流程努力程度、推荐意愿，还是续费、复购或留存风险？是否有实际行为数据？ | 总体评价考虑 X01/X02；努力考虑 X08；推荐考虑 G01；忠诚必须加入 G02 和实际行为。 |
| F06 | 努力程度 | 如果测量努力，您指的是完成某个任务、解决一次问题，还是整个关系中的便利程度？ | 努力必须绑定明确事件或任务；考虑 X08 CES；不能混用不同 CES 版本。 |
| F07 | 可用性或 UX | 您要评价一个刚完成的任务，还是整个系统的总体可用性？是否还要测量更广的体验？ | 单任务考虑 X04 SEQ；系统总体考虑 X05 SUS/X06 UMUX-LITE；广义体验考虑 X07 UEQ。 |
| F08 | 概念、广告或文案 | 您要判断一个方案是否值得继续，还是要在多个方案中选择更优方案？能否随机分配版本并保持曝光一致？ | 单方案考虑 N04 概念测试；多方案优先 N05/I01 随机化比较。 |
| F09 | 价格 | 您要探索可接受价格区间，还是估计不同明确价格下的购买概率？是否要同时权衡价格和功能？ | 价格区间考虑 P01；价格点概率考虑 P02；多属性取舍考虑 P03/N03。 |
| F10 | 采用、留存或 PMF | 受访者是潜在、试用还是长期活跃用户？要测采用意向、持续使用意向还是实际行为？能否连接行为窗口？ | 技术采用可考虑 G03 TAM/G04 UTAUT；持续使用要结合 G02 和实际行为；核心用户可考虑 G05。 |
| F11 | 品牌或传播 | 您要测无提示认知、提示认知、考虑、使用，还是品牌联想和感知质量？广告能否随机曝光？ | 认知漏斗考虑 B01；品牌资产考虑 B02；随机传播测试考虑 B03/I01。 |
| F12 | 分群 | 分群要支持什么动作？有多少样本和哪些行为、态度或需求变量？结果是否要在后续系统中复用？ | 变量与样本足够时考虑 S01 潜类别分析；复用时需要可解释、稳定的分类规则。 |
| F13 | 效果评估或前后测 | 是否可以随机分组？是同一批人前后测还是重复横截面？是否有对照组？哪个结果变量必须改变？ | 可随机则优先 I01；前后测考虑 I02；不能随机时说明混杂风险。 |
| F14 | 品类使用和态度 | 您要描述一个品类的使用场景、频率、品牌使用、需求和障碍吗？结果要支持市场进入、产品规划还是品牌策略？ | 需要使用和态度结构时考虑 D05 U&A；不要把 U&A 当成固定标准量表。 |
| F15 | 品牌健康追踪 | 这是单次品牌测量，还是需要跨波次追踪认知、考虑、使用和品牌联想？核心 KPI、样本和时间口径能否保持稳定？ | 单次认知漏斗考虑 B01；品牌资产考虑 B02；跨波次品牌健康追踪考虑 B04；需要固定核心 KPI 和轮换模块。 |

## 2. 通用执行约束

| ID | 建议提问 | 回答字段 | 影响 |
|---|---|---|---|
| U01 | 问卷通过什么方式实施？目标完成时长是多少？能否使用图片、视频或交互原型？ | mode；duration；stimulus_support | 影响题型、刺激材料、移动端布局和质量控制。 |
| U02 | 需要哪些语言和地区版本？是否已有正式翻译、回译或本地化要求？ | languages；markets；translation_status | 影响量表版本、测量等值性和跨市场比较。 |
| U03 | 是否涉及未成年人、健康、收入、身份、位置或其他敏感信息？是否有伦理、隐私或合规要求？ | sensitive_topics；ethics；privacy | 触发 [隐私基线](../../services/validation/privacy-baseline.md)；未成年人默认停止生成可投放版本。 |
| U04 | 是否有既有问卷、历史基准、日志、客服记录、交易数据或正式量表必须沿用？ | existing_instruments；benchmarks；behavior_data | 影响题项复用、口径连续性和辅助指标。 |
| U05 | 最终要交付什么：问卷文档、配额表、平台脚本、分析方案、交叉表模板还是报告？ | deliverables | 决定输出结构，以及是否需要变量命名、编码说明和分析计划等附加内容。 |

## 3. 对话示例

用户说：“我们想知道新功能要不要做。”

先问：

1. 结果要支持取消、保留、开发还是排序决策？
2. 要判断功能类型，还是在多个功能中排优先级？
3. 用户是否已经使用过相关产品，能否理解有和没有该功能的差异？
4. 是否还有价格、方案或服务水平需要一起权衡？
5. 目标用户是谁，哪些人需要排除？
6. 预计样本量、招募来源和问卷时长是什么？

判断示例：基本/期望/魅力路由到 N01 KANO；12 个功能的相对排序路由到 N02 MaxDiff；价格、功能和服务套餐一起取舍路由到 N03 选择型联合分析。
